## 🛠️ Como rodar o projeto localmente

Pré-requisitos
- Node.js (versão LTS)
- npm ou yarn

Instalação
- npm install

Ambiente de desenvolvimento
- npm run dev


O projeto estará disponível em:
- 👉 http://localhost:5173
